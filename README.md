# 📖 Habit Tracker

A modern habit tracker built with Vue 3 and TypeScript.

The application allows users to create habits, track daily completion, monitor progress throughout the month, and view overall statistics.


🔗 Live Demo: https://ksuwa.github.io/healthy_habit_tracker/

![Habit Tracker Preview](./screenshots/preview.png)

---

## ✨ Features

- ✅ Create and delete habits
- 📅 Monthly calendar view
- ✔️ Mark habits as completed for each day
- 🚫 Future dates are disabled
- 🎨 Automatic color generation for habits
- 📊 Statistics dashboard
- 💾 Data persistence using Local Storage
- 📱 Responsive layout

---

## 🚀 Getting Started

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

## ⚙️ Key Technical Decisions

- State management is implemented with Pinia.
- Local Storage is used instead of a backend API.
- Business logic is extracted into composables and utility functions where appropriate.
- TypeScript is used across the entire project.
- Components are designed to be reusable and loosely coupled.
